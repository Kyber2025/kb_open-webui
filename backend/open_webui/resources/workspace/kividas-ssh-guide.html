KIVIDAS / SSH WORKSPACE

你的云端 Claude 工作区

配置一次。以后在终端输入 claude，即可启动或回到云端 Claude Code 会话。

01 · 下载你的连接资料

  1. 登录 Kividas，打开 Code → SSH 工作区（推荐）。
  2. 确认页面显示“已绑定”。没有工作区时，请联系管理员绑定 SSH 账号；订阅也必须处于有效期内。
  3. 下载 个人连接 TXT，再按电脑系统下载通用脚本。多个工作区时，先选择实例。

所有实例共用同一份脚本；个人 TXT 决定连接哪台实例。TXT 含 SSH URL、主机指纹和首次配置密码，请妥善保存，勿发给其他人。免密私钥在你的电脑上生成。

02 · 运行配置脚本

Mac / Linux

将文件下载到“下载”目录。打开终端，粘贴：

bash ~/Downloads/kividas-ssh-setup.sh

按提示把个人连接 TXT 拖入终端并回车。Linux 也可以输入文件的完整路径。文件在其他目录时，请替换路径。请通过终端运行 .sh，不要双击文件。需要系统提供 ssh、sftp、ssh-keygen 和 ssh-keyscan。

Windows PowerShell

在 PowerShell 粘贴：

powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME\Downloads\kividas-ssh-setup.ps1"

按提示拖入 TXT 或粘贴完整路径。脚本支持 Windows PowerShell 5.1 及 PowerShell 7；请先在 Windows“可选功能”中安装 OpenSSH 客户端（8.6 或更新版本）。配置过程中本机 .NET 登录助手临时读取密码，完成后删除；无需安装自定义 Claude 客户端。

配置会依次检查资料、校验实例指纹、注册本机密钥、安装快捷命令。显示“配置完成”后，关闭并重新打开终端。

03 · 开始使用

命令用途
claude启动或恢复云端 Claude 会话
claude-ssh打开或恢复远程终端，执行 Git 等命令
claude-sftp在终端上传、下载文件；可以与 SSH 同时使用

这些命令操作云端 /workspace/claude 下的文件。配置后，本机 claude 快捷命令优先连接该工作区。重复运行脚本可更新配置，已有本机密钥会复用；导入另一份 TXT 会切换快捷命令的目标工作区。

04 · 用 Git 管理代码

claude-ssh
cd /workspace/claude
git clone https://github.com/你的用户名/你的仓库.git
cd 你的仓库
claude

私有仓库请使用你自己的 Git 凭据，通过 Git 提示输入访问令牌或使用仓库允许的授权方式。不要把令牌写进 clone URL、提交文件或聊天提示。修改后检查 diff、测试，再 commit 和 push。未推送的提交仅保存在云端。

05 · 终端 SFTP 传文件

claude-sftp
pwd
lpwd
lcd /你的本地项目目录
put -r 项目文件夹
get -r 远程文件夹
bye

lcd 切换本地目录，cd 切换远程目录。路径有空格时使用双引号。SSH 和 SFTP 可分别在两个终端窗口运行。

06 · 掉线、恢复与故障排查

  • 网络断线：重新运行同一个快捷命令。交互式会话会保留，重新连接可回到原终端；实例重启或解绑会结束会话。
  • Mac 闲置：快捷连接期间会阻止自动系统休眠，屏幕仍可关闭。合盖、手动睡眠、切换网络仍可能断线。
  • Permission denied：确认订阅有效且仍绑定同一工作区；绑定变更后下载新的 TXT 并重新配置。
  • 指纹不一致：脚本会停止，避免连接到错误服务器。刷新页面并重新下载 TXT；仍失败请联系管理员，不要关闭指纹校验。
  • 找不到 claude：重新打开终端。Mac/Linux 可执行配置完成时给出的 source 命令；Windows 可用脚本末尾显示的完整路径启动。
  • 配置卡住或无法连接：确认网络可访问页面显示的 SSH 地址和端口，稍后重试；向管理员提供错误文字与实例名，不要发送 TXT 或密码。
  • 卸载快捷配置：Mac/Linux 删除 shell 配置中的 BEGIN KIVIDAS CLAUDE 至 END KIVIDAS CLAUDE 区块；Windows 从用户 PATH 移除 %USERPROFILE%\.kividas\bin 并删除该目录中三个对应 .cmd 快捷文件。仅卸载客户端不会解绑服务器账号。

07 · 订阅到期与文件清理

到期前务必备份。

订阅到期后，后台自动解除 SSH 用户绑定：密码和本机登录密钥失效、SSH/SFTP 与运行中会话结束、工作区全部文件被清空，包括隐藏文件、Git 凭据和未推送提交。移除绑定或删除账号同样会清理工作区。

请在有效期内将代码推送到自己的 Git 仓库，或用 SFTP 下载备份。续费不会恢复已删除文件；需重新绑定并下载新的连接 TXT。网络断开后的会话恢复不代替数据备份。
